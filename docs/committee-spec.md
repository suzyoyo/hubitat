# 管委會端規格：角色權限與狀態顏色

Oct 11, 2026 · @hakukanojyo

## 怎麼看這份文件

權限表的「依據」欄分兩種：**已決定**是團隊已經拍板的；**建議**是依目前的畫面和社區管理慣例先填的，請確認後改成已決定。

- ✓ 可以做

- ✗ 不能做

- 本人 = 只能處理自己發的或自己被交辦的

職稱（例如修繕委員、總幹事）只用來顯示，不影響權限。一般委員和管理人員都可以填職稱。

## 角色權限表

只有主委和副主委能交辦事情給別人、審核公告；管理人員不是委員，不能發起或簽核提案。廠商評分功能已拿掉。

**公告審核規則**：管理人員發的公告，主委或副主委其中一位通過就發布；主委發的由副主委審核，副主委發的由主委審核。財務委員和一般委員不能發布公告。

## 待確認

所有問題都已決定。表中標「建議」的格子先照表實作，之後有問題再改。

- [x] **緊急公告**：先發布，再通知審核人事後確認。

- [x] **副主委代理**：隨時都能管理成員和換屆交接，不需要先開啟代理狀態。

- [x] **全域「＋」選單**：新增交辦、登記報修、發布公告、上傳文件、快速留存，五項都留。

- [x] **延後的決議**：出現在「決議事項」列表（有「延後」篩選），也放進換屆交接包的「未執行與延後的決議」。

已經定了：「廠商名冊不顯示電話」只針對住戶端，管委會端維持顯示電話和撥號。

## 狀態 Badge 顏色規則

顏色只用來標出「需要注意的事」：紅色最急，灰色不用管。卡片元件上用「狀態」屬性切換，不要替換子元件，也不要覆寫顏色。

下面這張表是**管委會端**（含管理人員）的規則；住戶端用另一套，寫在本節最後。

| 顏色   | 元件              | 意思                       | 用在                                                                                                                                                |
|--------|-------------------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| 紅     | Badge/Destructive | 已經出問題，要馬上處理     | 逾期 N 天、嚴重逾期、今天到期、保養逾期、尚未受理、尚未指派、無合約                                                                                 |
| 橘     | Badge/Secondary   | 輪到你處理，或快到期了     | 剩餘 N 天、N 天後到期、即將到期、保養將到期、等我簽核、待我確認、待簽核、待補、待整理、待發布、待處理、未執行、待維修                               |
| 藍     | Badge/Default     | 流程進行中，在等別人       | 進行中、處理中、已受理、簽核中、維修中、交辦人確認中、待接受、待生效                                                                                |
| 灰     | Badge/Outline     | 已結束、正常，或只是分類   | 已完成、已發布、簽核完成、合作中、現行有效、正常使用中、已停用、已撤回、延後、僅報告；類型和地點標籤（臨時會議、維護、B 棟）；數量（4 戶附議、2/5） |
| 無底色 | Badge/Ghost       | 欄位旁的補充標註，不是狀態 | 選填、可多選、儲存時間                                                                                                                              |

**不確定用哪個顏色時，依序問：**

1.  已經出問題了嗎？是 → 紅

2.  需要看到這張卡的人動作嗎？是 → 橘

3.  事情還在進行，只是在等別人？是 → 藍

4.  都不是 → 灰

**位置規則**：狀態 badge 一律放在卡片第一行（或標籤那一行）的最右邊；類型、地點標籤放左邊。卡片右上角有箭頭時，badge 放在箭頭左邊。

**同一個狀態只用一種顏色**：例如「剩餘 5 天」不管出現在待辦還是提案，都是橘色。

### 住戶端規則

住戶不需要知道管理流程，只要知道「會不會影響我、要不要我做什麼」。所以住戶端不顯示逾期，紅色代表「現在正在影響你」。

| 顏色 | 元件              | 住戶端的意思             | 用在                                                         |
|------|-------------------|--------------------------|--------------------------------------------------------------|
| 紅   | Badge/Destructive | 現在正在影響你           | 施工中、進行中・共 N 天、今天停水、緊急公告                  |
| 橘   | Badge/Secondary   | 需要你動手做的事         | 待繳費、待投票、請補充通報資料                               |
| 藍   | Badge/Default     | 跟你有關，但不用你做什麼 | 與你相關、明天施工、已收到、處理中、待生效                   |
| 灰   | Badge/Outline     | 已結束，或只是分類       | 已完成、通過、現行有效；公告、會議、文件類型；身分；一般日期 |

住戶端不顯示逾期天數、附議人數、處理人姓名。
