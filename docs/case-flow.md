## 2. 交辦給管理人員怎麼記（要先決定，後面都靠它）

`data-model.md` 寫「主委或副主委受理後再交辦給管理人員，資料上要怎麼記還沒定」。兩個做法：

| | A. 案件上多一個欄位 `handlerId`（處理的管理人員） | B. 另開一筆交辦，用 `caseId` 連到案件 |
|---|---|---|
| 資料 | 案件多一欄 | 用現成的交辦（`tasks.js` 已經有 `caseId`） |
| 交辦的確認、退回、撤回 | 要另外做 | 現成的 `confirmTask`、`returnTask`、`withdrawTask` 都能用 |
| 待辦 | 要改 `getMyTodos` | 「交辦給我的」「待我確認」已經會出現 |
| 假資料 | 要補 | **已經是這樣寫的**（`TASK-092` 連到 `CASE-20260925-003`，張管理員在案件上寫處理紀錄） |

**建議 B**。規則：

- 案件的負責人（`assigneeId`）還是受理的主委或副主委，不會換人
- 一件案件同時只能有一筆「進行中」的交辦。撤回或被退回後可以再交辦
- 被交辦的管理人員可以在這件案件上派廠商、寫處理紀錄、標記完工（權限表本來就是管理人員都能做，這裡不另外限制）

## 3. 每一步的規則

「住戶看到」就是處理紀錄的 `residentText`，住戶的通報詳情頁會自動顯示（沒寫就不給住戶看）。

### 3-1 受理 `acceptCase(id, userId, { deadline, category, equipmentId })`
- 誰：主委、副主委、管理人員（權限表）
- 什麼時候：待受理
- 做什麼：狀態 → 已受理；負責人 = 受理的人；處理期限（必填）；問題分類（住戶通報時先歸「其他」，這時改成正確的，選填）；關聯設備（選填，有選的話結案時才會進維修歷史）
- 紀錄：「已受理」／「主委 李委員受理並設定處理期限 10/8」
- 住戶看到：「管委會已受理。」或「管理人員已受理。」（照現在假資料的寫法）
- ❓ 處理期限要不要依「緊急」給預設值（例如緊急 3 天、一般 7 天）

### 3-2 交辦 `createTask(userId, { title, content, assigneeId, deadline, caseId })`
- 誰：主委、副主委（權限表）
- 做什麼：新增一筆進行中的交辦；有 `caseId` 的話，案件多一筆紀錄
- 紀錄：「交辦」／「主委 李委員交辦給 管理員 張管理員（TASK-105）」
- 住戶看到：不寫（住戶不需要知道內部分工）
- 被交辦的人：待辦裡出現在「交辦給我的」（現成的）
- 這個函式也給「會議決議交辦」用（那時 `caseId` 不傳）

### 3-3 派廠商 `assignVendor(id, userId, vendorId)`
- 誰：主委、副主委、管理人員
- 什麼時候：已受理、施工中（可以換廠商）
- 做什麼：記下廠商；狀態 → 施工中
- 紀錄：「派廠商」／「張管理員指派 大同電梯」
- 住戶看到：「已安排廠商處理。」（不寫廠商名稱）
- ❓ 「施工中」對沒有真的施工的事（例如聯繫廠商報價）有點怪，要不要改叫「處理中」

### 3-4 處理紀錄 `addCaseLog(id, userId, { text, showToResident })`
- 誰：主委、副主委、管理人員
- 什麼時候：還沒結案
- 紀錄：「處理紀錄」／寫的內容
- 住戶看到：勾了「讓通報的住戶看到」才給看，內容和管理端一樣
- ❓ 住戶看到的要不要另外寫一句（管理端的寫法可能有廠商名稱、報價）。另外寫比較安全，但多一個欄位要填

### 3-5 標記完工 `completeCase(id, userId, { note, photos })`
- 誰：主委、副主委、管理人員
- 什麼時候：施工中
- 做什麼：記下完工紀錄（`completion`）；狀態 → 待驗收
- **有連到這件案件、交辦給這個人、進行中的交辦，會一起回報完成**（交辦的回報備註就用完工備註），不用再到交辦頁按一次
- 紀錄：「廠商已完工」／完工備註
- 住戶看到：「維修已完成，等待確認。」
- 待辦：負責人的待辦出現這件（主委是「我負責的案件」、管理人員是「待標記完成」，現成的）

### 3-6 驗收結案 `closeCase(id, userId, { cost, rating })`
- 誰：**案件負責人**（受理的那個人）。主委或副主委受理、交辦出去的，就是主委或副主委結案
- 什麼時候：待驗收
- 做什麼：狀態 → 已結案、記下結案時間；有連到的交辦（待確認）一起確認完成
- 維修費用（選填）：只有委員填得了，管理人員結案時沒有這一欄（管理人員看不到費用，權限表 2026-10-14）
- 廠商評分（選填）：1～5 分＋評語
- 紀錄：「已結案」／「主委 李委員驗收結案」
- 住戶看到：「已完成維修，感謝你的通報。」
- 驗收不通過：❓ 要不要做「退回重修」（待驗收 → 施工中）。示範可以先不做

### 3-7 變成維修歷史（結案時自動做）
- 案件有關聯設備的話，那台設備的紀錄多一筆：日期＝結案日、類型＝維修、內容＝案件標題、廠商、費用、`caseId`
- 設備狀態：❓ 受理時設備變「待維修」、派廠商變「維修中」、結案變回「正常」，要不要做（做了設備清冊才看得出變化）
- 沒有關聯設備的案件（例如住戶噪音）不進維修歷史，案件本身就是紀錄
